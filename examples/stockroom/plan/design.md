# Design handoff

Use a calm, high-contrast household inventory layout. Place the add form first,
filters next, and then a simple list. Wide screens may group fields in one row.
Stack fields on narrow screens. Native controls have visible labels and focus.
Show an empty-list message, saving state, validation message, and network failure
status. Keep draft values after a failed save. Use buttons labeled Mark bought
and Mark needed. Keep the current filters when data refreshes.
